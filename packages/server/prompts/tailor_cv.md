# Задача: адаптировать резюме под вакансию

На входе базовое резюме (JSON), вакансия и профиль. Верни новую версию резюме той же структуры и список изменений. Это переупаковка настоящего опыта, а не сочинение.

## Порядок работы

1. Разбор вакансии: выпиши для себя обязательные и желательные требования, ключевые слова стека, что упоминается несколько раз.
2. Сопоставление: какие места, буллеты и навыки из базового резюме это закрывают. Что не закрывается - не выдумывай.
3. Адаптация (что можно менять):
   - `title` - под название вакансии, если это правда про соискателя (например «Go-разработчик» для Go-вакансии). Без Senior/Lead, если их нет в базе.
   - `about` - переписать под роль: 2-4 предложения, ключевые слова вакансии естественно, годы опыта и стек из базы. До 700 символов.
   - `skills` - переставить группы и элементы: релевантное вакансии первым. Добавлять можно только то, что есть в `profile.verified_skills` или в базовом резюме.
   - `jobs[].bullets` - переставить (релевантное первым), переформулировать, убрать нерелевантные, если буллетов больше 4-5. Формулировка: глагол + что сделал + масштаб/результат + технология. Числа только из базы; не придумывай метрики. Каждый буллет до 220 символов, одна-две строки.
   - `jobs[].summary`, `jobs[].stack` - переупорядочить, стек ограничить релевантным, ничего не добавляя.
4. Что менять нельзя:
   - Состав и порядок `jobs`: каждая компания, роль, период, локация остаются как есть. Ни одного места работы не удалять и не добавлять.
   - `education` - как есть.
   - `name`, `contacts` - как есть.
   - Технологии вне `profile.verified_skills` и базового резюме не появляются нигде. Список «никогда не заявлять» - ни в каком поле.
   - Не менять смысл достижения: «участвовал» не превращается в «руководил».
5. Объём: одна страница - суммарно не больше буллетов, чем в базе.
6. Язык резюме - как в базовом. Слова из вакансии используй в точной формулировке (для ATS), но без повторов одного термина много раз.

`changes` - список коротких строк на русском, что изменено и зачем: «about переписан под backend на Go», «в Компании X буллет про Redis поднят первым», «удалён буллет про Vue как нерелевантный».

## Схема ответа

```json
{
  "cv": {
    "title": string,
    "name": string,
    "contacts": { "email": string, "phone": string, "telegram": string, "github": string, "city": string },
    "about": string,
    "skills": [ { "name": string, "items": string[] } ],
    "jobs": [ { "company": string, "role": string, "period": string, "location": string, "summary": string, "bullets": string[], "stack": string[] } ],
    "education": [ { "institution": string, "degree": string, "period": string, "note": string } ]
  },
  "changes": string[]
}
```

Верни только JSON.
