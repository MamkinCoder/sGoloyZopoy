## Порядок работы

1. Разбери вакансию и сопоставь с базовым резюме по правилам выше: какие места, буллеты и навыки закрывают обязательные требования.
2. Что можно менять:
   - `title` - под название вакансии, если это правда про соискателя.
   - `about` - 2-4 предложения под роль, до 700 символов.
   - `skills` - переставить группы и элементы. Добавлять можно только то, что есть в `profile.verified_skills` или в базовом резюме.
   - `jobs[].bullets` - переставить, переформулировать, убрать нерелевантные, если буллетов больше 4-5. Каждый буллет до 220 символов.
   - Если есть «База знаний»: в ней только истории компаний из базового резюме. Историю можно превратить в буллет той же компании (совпадает `company`), заменив менее релевантный буллет, или уточнить ею формулировку. Историю одной компании никогда не переносить в другую.
   - `jobs[].summary`, `jobs[].stack` - переупорядочить, стек ограничить релевантным, ничего не добавляя.
3. Что менять нельзя:
   - Состав и порядок `jobs`: каждая компания, роль, период, локация остаются как есть. Ни одного места работы не удалять и не добавлять.
   - `education`, `name`, `contacts` - как есть.
   - Стаж: общий и по технологиям бери дословно из `about` базового резюме и `profile.experience`. Не пересчитывай по датам и не занижай («больше года на Go» вместо «2,5+ года» - ошибка).
   - Технологии вне `profile.verified_skills` и базового резюме не появляются нигде. Список «никогда не заявлять» - ни в каком поле.
4. Объём: одна страница - суммарно не больше буллетов, чем в базе. Язык резюме - как в базовом.

`changes` - список коротких строк на русском, что изменено и зачем: «about переписан под backend на Go», «в Компании X буллет про Redis поднят первым», «удалён буллет про Vue как нерелевантный».

## Схема ответа

```json
{
  "cv": {
    "title": string,
    "name": string,
    "contacts": { "email": string, "phone": string, "telegram": string, "github": string, "city": string },
    "about": string,
    "skills": [ { "name": string, "items": string[] } ],
    "jobs": [ { "company": string, "role": string, "period": string, "location": string, "summary": string, "bullets": string[], "stack": string[] } ],
    "education": [ { "institution": string, "degree": string, "period": string, "note": string } ]
  },
  "changes": string[]
}
```

Верни только JSON.
