## Как решать

Цель соискателя - собеседования. Любая техническая роль рядом с его стеком подходит: backend, frontend, fullstack, DevOps, SRE, platform / infra, data engineering, ML / AI engineering, QA automation с кодом. Senior, «Старший» и «Ведущий разработчик» (в крупных компаниях это грейд senior, не руководитель) - откликайся (опыт 5 лет).

Отказ (`apply: false`) только если хотя бы одно:
- Lead / Head / Architect / Тимлид / руководитель, или явно требуют 7+ лет опыта.
- Основной стек вакансии совсем не пересекается с `verified_skills` (например только 1C, PHP/Bitrix, C++, .NET, Java-only, мобильная нативка без React Native).
- Это не техническая роль: продажи, менеджер без разработки, дизайн, поддержка первой линии, бизнес-аналитик без кода.
- Требуют навык из списка «никогда не заявлять» как ключевой и единственный.

Иначе `apply: true`. Сомневаешься - откликайся, соискателю нужен объём откликов.
Резюме: то, у которого `direction` и `key_skills` больше всего пересекаются с вакансией.
`direction` - направление вакансии одним словом из списка направлений профиля (например go-backend, node-backend, react, fullstack) или ближайшее.
`seniority` - junior / middle / senior / lead по тексту вакансии.
`red_flags` - короткие пометки: «тест», «5+ лет», «нужен Kubernetes», «зарплата ниже вилки» и т.п. Пустой массив, если нет.
`reason` - одно предложение, почему такое решение.

Соответствие резюме (`resume_fit`), только если `apply: true`:
- `"good"` - только если `direction` выбранного резюме совпадает с `direction` вакансии И в названии резюме есть главный стек вакансии (например «Go-разработчик» для Go-вакансии).
- `"poor"` - во всех остальных случаях, например вакансия go-backend, а в пуле только fullstack-резюме, или название резюме не про главный стек вакансии. Тогда обязательно заполни `tailored` - резюме под эту вакансию:
  - `title` - желаемая должность в стиле hh.ru, без Senior / Lead / Ведущий / Тимлид.
  - `about` - 3-5 предложений «О себе» только из фактов профиля, без ссылок и контактов.
  - `key_skills` - 8-15 навыков ТОЛЬКО из `profile.verified_skills`, сначала те, что есть в вакансии.
- При `"good"` или `apply: false` поле `tailored` не нужно.

## Схема ответа

```json
[
  {
    "vacancy_id": number,          // id вакансии из списка
    "apply": boolean,
    "reason": string,              // одно предложение
    "resume_id": string,           // hh id резюме из пула, "" если apply=false
    "cover_letter": string,        // 3-6 предложений или ""
    "direction": string,
    "seniority": string,           // junior | middle | senior | lead
    "red_flags": string[],
    "resume_fit": string,          // good | poor
    "tailored": {                  // только при resume_fit=poor, иначе не указывай
      "title": string,
      "about": string,
      "key_skills": string[]
    }
  }
]
```

Верни только JSON.
