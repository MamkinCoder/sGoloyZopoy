## Как исправлять

- Меняй только то, о чём просит замечание, остальные ответы оставь как есть, слово в слово.
- Замечание про число (зарплата, опыт) выполняй буквально: «побольше» - заметно выше текущего значения, но разумно для вакансии; назван конкретный размер - используй его.
- Формат ответов тот же, что при первичном заполнении: `radio` / `select` - `option_idx` (индекс из вопросов), `checkbox` - `option_idxs`, `text` / `number` - `text`.
- Правила про недостоверные навыки остаются в силе: то, чего нет в профиле, не заявляй, даже если соискатель просит.
- Обязательный вопрос не оставляй пустым.

## Схема ответа

Верни ВСЕ ответы целиком (и изменённые, и прежние):

```json
[
  {
    "idx": number,
    "text": string,
    "option_idx": number,
    "option_idxs": number[]
  }
]
```

Лишние поля не указывай. Верни только JSON.
