# Задача: универсальный профиль соискателя на Хабр Карьере

На Хабр Карьере у соискателя ОДИН профиль (резюме), и бот откликается им на все вакансии, которые подходят по его направлениям (`profile.directions`, `profile.hh_queries`). Поэтому профиль должен быть универсальным в рамках этих направлений и насыщенным: работодатель из любого из них должен сразу увидеть свою область и технологии. Всё только из фактов ниже.

{{> _rules}}

Для этого профиля (это не письмо) дополнительно:
- «О себе» и описания опыта - несколько абзацев, переносы строк разрешены. Списки через «- » внутри описания опыта разрешены. Тон спокойный и деловой, без «Привет!».
- Ссылок, email, телефонов нет нигде.

## Что вернуть

- `title` - заголовок резюме до 80 символов, широкий, по направлениям и главным навыкам из фактов (например «Fullstack-разработчик: Go, Node.js, React» или «Руководитель проектов: IT, Scrum, ELMA365»). Без Senior / Lead, если их нет в фактах.
- `specializations` - 1-2 id из списка выше, самые подходящие по фактам и направлениям (разработчику - разработческие, руководителю проектов - «Менеджер проекта», «Деливери-менеджер» и подобные). Если ничего не подходит - пустой список.
- `qualification` - одно из Junior / Middle / Senior. Senior только если факты это прямо поддерживают; иначе Middle.
- `about` - «О себе», 4-6 абзацев через пустую строку: кто он и сколько лет опыта (фраза `profile.experience`), основные направления работы и технологии или инструменты по каждому (из `profile.summary`, `profile.verified_skills`, базовых резюме и базы знаний), реальные проекты и результаты, формат работы (`profile.work_formats`, `profile.extra`, релокация). Конкретика и названия инструментов, без общих слов про характер.
- `skills` - до 30 навыков, самые востребованные по его направлениям первыми. Только из `profile.verified_skills` и стека базовых резюме; если их меньше 30 - столько, сколько есть. Названия в общепринятом написании, как в словаре Хабра (например Golang, Node.js, PostgreSQL, Scrum, Jira).
- `experiences` - по одному объекту на каждое место работы из «Что сейчас в профиле на Хабре», `company` дословно как там. `description` - 2-3 предложения обязанностей, затем 3-5 достижений строками «- ...» по формуле буллетов, затем строка «Технологии: ...». Для каждого места бери факты этого места из базовых резюме, из историй «Базы знаний» с той же компанией (одно и то же место может называться чуть по-разному: подразделение, сокращение, опечатка - сопоставляй по сходству названия и периоду) и из его текущего описания. Места, которого нет в базовых резюме, переписывай только из его текущего описания. Не добавляй мест работы и не меняй сроки.
- `new_experiences` - для каждого места работы из базовых резюме, которого НЕТ в «Что сейчас в профиле на Хабре»: `company` дословно как в резюме, `description` - 2-3 предложения обязанностей, затем 3-6 достижений строками «- ...», затем «Технологии: ...». Только факты этого места из базовых резюме и базы знаний. Должность, сроки и город не пиши: их берёт код из резюме.
- `notes` - короткие пометки для соискателя: что намеренно не включено и почему, что проверить руками.

Схема ответа - в конце промпта.
