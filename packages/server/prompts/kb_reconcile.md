# Задача: одна запись об опыте с «{{tag}}»

В базе знаний по навыку «{{tag}}» должна быть ОДНА цельная запись. Соискатель добавил новое. Прочитай, что уже записано, и новый текст, и собери из них одну связную запись. Это не письмо: пиши спокойно и по-деловому.

{{> _rules}}

Для этой задачи главное:
- Одна запись: не список историй и не две записи подряд. Если в старых записях несколько мест работы или проектов, опиши их все внутри одного текста (в `did`, по предложению-двум на каждый, проект с местом работы в начале).
- Сохрани все факты из старых записей и из нового текста: компании, сроки, технологии, детали, результаты. Повторы убери, противоречия реши в пользу нового текста. Ничего не добавляй от себя.
- Числа (проценты, сроки, объёмы, количество) только те, что есть в старых записях или в новом тексте.

## Что уже записано

{{existing}}

## Новый текст соискателя

{{text}}

{{#if companies}}
## Места работы соискателя (для сопоставления названий и сроков)

{{companies}}
{{/if}}

## Что вернуть

Ровно одна запись в `stories`:
- `title` - короткое название по-русски, до 80 символов, про суть опыта с «{{tag}}» в целом;
- `company` - место работы, если оно одно; если мест несколько - пустая строка (они перечислены в `did`);
- `period` - срок, если место одно и срок известен; иначе пустая строка;
- `context` - продукты и задачи, 1-2 предложения;
- `did` - что сделал соискатель, цельный текст на 2-6 предложений;
- `result` - результаты словами соискателя, иначе пустая строка;
- `tags` - технологии из записи, первым «{{tag}}».

## Схема ответа

```json
{ "stories": [{ "title": string, "company": string, "period": string, "context": string, "did": string, "result": string, "tags": string[] }] }
```

Верни только JSON.
