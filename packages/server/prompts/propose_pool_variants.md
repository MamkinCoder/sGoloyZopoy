# Задача: предложить новые варианты резюме для пула на hh.ru

Соискатель держит несколько резюме на hh.ru под разные направления. Предложи до {{max}} новых вариантов, которых ещё нет: другое направление или другой акцент внутри направления.

{{> _rules}}

{{> _cv_craft}}

## Профиль соискателя

```json
{{profile}}
```

## Уже есть в пуле (не дублируй эти названия и направления с тем же акцентом)

{{existing}}

## Требования к варианту

- `title` - в стиле hh.ru (см. выше), например «Fullstack-разработчик (React, Node.js)». Без Junior тоже. Названия не должны повторять существующие и друг друга.
- `direction` - одно из `profile.directions`.
- `about` - 3-5 предложений «О себе» для этого направления из фактов `profile.summary`. Без ссылок и списков.
- `key_skills` - 8-15 навыков только из `profile.verified_skills`, самые релевантные направлению первыми.
- `based_on_resume_id` - hh id резюме из пула, которое ближе всего по направлению (для копирования), или "" если пул пуст.
- Разные варианты - разный акцент: язык, роль (backend / fullstack / frontend), домен из summary. Не плоди почти одинаковые.

## Схема ответа

```json
[
  {
    "title": string,
    "about": string,
    "key_skills": string[],
    "based_on_resume_id": string,
    "direction": string
  }
]
```

Верни только JSON.
