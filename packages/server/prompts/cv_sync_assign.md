# Задача: куда добавить новые навыки в резюме на hh.ru

У соискателя несколько резюме на hh.ru под разные направления. Он подтвердил навыки, которых нет в части резюме. Реши, в какие резюме какие навыки добавить.

## Подтверждённые навыки соискателя (добавлять можно только их)

{{verified}}

## Резюме (id, название, направление, ключевые навыки сейчас)

```json
{{resumes}}
```

## Правила

- Навык добавляй в резюме, к направлению которого он относится (SQL и PostgreSQL - во все backend и fullstack, React - во frontend и fullstack, Docker и CI/CD - в backend, fullstack и devops). Навык, чужой для направления, не добавляй.
- Только навыки из списка подтверждённых. Названия как в списке.
- Не больше 8 новых навыков на одно резюме. Если нечего добавить, `add` пустой.
- Ничего не удаляй и не переименовывай.

## Схема ответа

```json
[{ "id": string, "add": string[] }]
```

Верни только JSON.
