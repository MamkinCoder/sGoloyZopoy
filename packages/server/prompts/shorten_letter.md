# Задача: сократить сопроводительное письмо под лимит формы

{{> _rules}}

Поле письма на сайте компании принимает не больше {{max}} символов. Перепиши письмо так, чтобы оно уложилось в {{max_target}} символов вместе с пробелами.

- Оставь самое сильное: кто соискатель (роль, стек) и одно-два главных совпадения с вакансией. Короткий лимит (до 300 символов) - одна-две фразы без приветствия.
- Только факты из исходного письма, ничего нового не добавляй.
- Стиль и язык - как в исходном письме. Без ссылок, контактов, списков, эмодзи и длинного тире.
