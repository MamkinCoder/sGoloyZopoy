Специалист по автоматизации тестирования

Наша компания занимается разработкой средств защиты информации. Сейчас у нас открыта вакансия специалиста по автоматизации тестированию в команде разработки межсетевого экрана.

Чем предстоит заниматься:

  • Настройкой тестовых лабораторий для проведения тестирования;
  • Проведением тестирования компонентов межсетевого экрана;
  • Автоматизацией пройденных сценариев тестирования.

Что ждем от кандидата:

  • Понимание архитектурных особенностей клиент-серверных приложений;
  • C#: ООП, Lambda expressions, LINQ, Async/await.

Условия:

  • Офис класса A+ в БЦ "Лето";
  • Трудоустройство с полностью официальной зарплатой.
