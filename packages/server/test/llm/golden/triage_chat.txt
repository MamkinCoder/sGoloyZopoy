# Задача: разобрать новые сообщения работодателя в чате (без ответа)

Ты не пишешь ответ. Ты решаешь, что нужно этому ходу работодателя, чтобы ответ потом написали правильно.

## Навыки соискателя, которые уже известны

Есть: Go, TypeScript, Node.js, React, Redis, Docker, CI/CD, PostgreSQL, Linux

Нет (никогда не заявлять): Kubernetes, Kafka, RabbitMQ, ClickHouse

## Переписка (старые сообщения выше, последнее - внизу)

[работодатель 2026-09-22T10:00]
Здравствуйте! Спасибо за отклик. Подскажите, сколько лет работаете с Go?

[соискатель 2026-09-22T10:05]
Здравствуйте. Около двух лет в коммерческой разработке.

[работодатель 2026-09-22T10:10]
Отлично. А с Kubernetes работали? И готовы ли к удалёнке?

## Новые сообщения работодателя (на них нужен ответ)

[работодатель 2026-09-22T10:10]
Отлично. А с Kubernetes работали? И готовы ли к удалёнке?

## Что вернуть

`kind` - одно значение:
- `question` - спрашивают про опыт, навыки, условия, готовность, предлагают пообщаться; сюда же работодатель (или его ИИ-помощник hh), который написал первым с вакансией: «Хотите, расскажу подробнее?», «Интересно ли узнать больше?», «Хотите откликнуться?»;
- `scheduling` - назначают или согласуют время звонка / собеседования;
- `test_task` - предлагают тестовое задание;
- `rejection` - отказ;
- `bot_survey` - чат-бот работодателя с вопросами или кнопками;
- `ack_only` - ответ не нужен: «спасибо, посмотрим», «резюме передано», автоуведомление без вопроса.

`topics` - технологии и навыки, про которые работодатель спрашивает в новых сообщениях, есть ли они у соискателя (опыт с Jest, знание Kubernetes, писали ли на Vue). Правила:
- Только то, о чём прямо спрашивают в новых сообщениях. Стек из описания вакансии без вопроса не считается.
- Одно короткое каноническое название на навык: «Jest», «Vitest», «Kubernetes», «PostgreSQL». Если навык уже есть в списках выше - пиши его точно так же, как там.
- Общие вещи (опыт работы, зарплата, формат, релокация, график, английский уровня «читаю документацию») - не навыки, их не пиши.
- Нет вопросов про навыки - `[]`.

## Схема ответа

```json
{
  "kind": "question" | "scheduling" | "test_task" | "rejection" | "bot_survey" | "ack_only",
  "topics": string[]
}
```

Верни только JSON.
