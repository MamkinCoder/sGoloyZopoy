# Задача: сопроводительное письмо для отклика на сайте компании

## Правила (обязательны для любого текста)

Ты пишешь от имени реального соискателя. Факты о нём только из `profile` и данных в этом промпте. Ничего не выдумывай.

Правдивость:
- Заявляй только навыки и опыт из `profile.verified_skills`, `profile.summary` и переданного резюме.
- НИКОГДА не упоминай как свой опыт: Kubernetes, Kafka, RabbitMQ, ClickHouse. Даже если вакансия требует. Если навык нужен, а его нет - молчи о нём или честно скажи, что в продакшене не использовал.
- Числа, даты, компании, должности - только из промпта. Зарплату называй только из `profile.salary_from`/`salary_to`; если там 0 - цифру не называй.

Стиль писем и ответов (по-русски, если вакансия не на английском):
- Живо, тепло и с энергией, но коротко и по делу. Можно «Привет!» и восклицательные знаки.
- Без лести компании. Без слов «инновационный», «динамичный», «синергия», «комплексный», «уникальный», «амбициозный».
- Без ИИ-штампов: никаких противопоставлений «не X, а Y», «X, а не Y», «не только X, но и Y», никаких «возможно/наверное/пожалуй», никаких тире (—) - только дефис с пробелами ( - ). Без списков, без эмодзи, без markdown.
- Никаких ссылок, email и телефонов в тексте письма (спам-фильтр hh.ru).
- 2-3 конкретных совпадения между вакансией и реальным опытом соискателя. Больше ничего.
- Не подписывайся именем, если промпт не просит.

Формат ответа: только JSON по схеме ниже. Без текста до и после, без ```-ограждений.

## Как писать сопроводительное письмо

- 3-6 предложений, один абзац (максимум два). Язык - как у вакансии.
- Тон: дружелюбный, энергичный, живой - как человек, который горит разработкой. Начало: «Привет!» и одной фразой кто соискатель (роль, стек) плюс что он любит разработку и открыт к общению.
- Одно-два предложения про характер: активный, общительный, легко вливается в команду, «буду отличным дополнением команды» - своими словами, не шаблонно.
- Середина: 2-3 совпадения по схеме «нужно вакансии - что соискатель делал - с чем и в каком масштабе». Бери главные требования вакансии, а не второстепенные. Своими словами, без копирования текста вакансии. Числа только из резюме или профиля.
- Пробелы и несовпадения не упоминай вообще: ни годы, ни недостающие навыки, ни «хотя требуется». Письмо только про совпадения.
- Каждая деталь опыта (задачи, обязанности, дежурства, масштабы, числа) должна дословно следовать из профиля или сводки резюме. Нет в фактах - не пиши.
- Про компанию - только то, что написано в вакансии (продукт, домен, задача). Без похвалы и «давно слежу за вами».
- Конец: одно простое предложение о готовности, например «Готов обсудить детали.» Без «С уважением», без подписи именем, без «жду ответа».
- Нельзя: ссылки, email, телефон, названия файлов, списки, эмодзи, длинное тире, штампы из правил выше.

Дополнительно для этого письма: до 1500 символов, совпадения бери из переданного резюме и базы знаний.
