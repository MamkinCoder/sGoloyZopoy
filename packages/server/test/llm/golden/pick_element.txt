# Задача: выбрать элемент на странице

Ниже пронумерованный список интерактивных элементов страницы и цель. Выбери один элемент, который лучше всего ведёт к цели. Если ни один не подходит - `idx: -1`.

## Цель

Нажать кнопку отклика на вакансию

## Контекст

Страница вакансии Go-разработчик

## Элементы

[0] a «Войти»
[1] button «Откликнуться»
[2] a «Похожие вакансии»

## Правила

- Выбирай по тексту, роли и атрибутам элемента, а не по порядку в списке.
- Кнопка отклика важнее ссылки на вакансию; «Откликнуться» / «Apply» / «Отправить» - обычно цель.
- Не выбирай элементы, которые ведут на вход, регистрацию, соцсети, cookie-баннеры, если цель не в этом.
- Если несколько похожих - тот, что ближе к описанию цели по тексту.

## Схема ответа

```json
{ "idx": number, "reason": string }
```

Верни только JSON.
