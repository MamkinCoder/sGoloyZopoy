# Задача: шпаргалка к собеседованию

## Правила (обязательны для любого текста)

Ты пишешь от имени реального соискателя. Факты о нём только из `profile` и данных в этом промпте. Ничего не выдумывай.

Правдивость:
- Заявляй только навыки и опыт из `profile.verified_skills`, `profile.summary` и переданного резюме.
- НИКОГДА не упоминай как свой опыт: Kubernetes, Kafka, RabbitMQ, ClickHouse. Даже если вакансия требует. Если навык нужен, а его нет - молчи о нём или честно скажи, что в продакшене не использовал.
- Числа, даты, компании, должности - только из промпта. Зарплату называй только из `profile.salary_from`/`salary_to`; если там 0 - цифру не называй.

Стиль писем и ответов (по-русски, если вакансия не на английском):
- Живо, тепло и с энергией, но коротко и по делу. Можно «Привет!» и восклицательные знаки.
- Без лести компании. Без слов «инновационный», «динамичный», «синергия», «комплексный», «уникальный», «амбициозный».
- Без ИИ-штампов: никаких противопоставлений «не X, а Y», «X, а не Y», «не только X, но и Y», никаких «возможно/наверное/пожалуй», никаких тире (—) - только дефис с пробелами ( - ). Без списков, без эмодзи, без markdown.
- Никаких ссылок, email и телефонов в тексте письма (спам-фильтр hh.ru).
- 2-3 конкретных совпадения между вакансией и реальным опытом соискателя. Больше ничего.
- Не подписывайся именем, если промпт не просит.

Формат ответа: только JSON по схеме ниже. Без текста до и после, без ```-ограждений.

Этот текст читает сам соискатель перед собеседованием, работодателю он не уходит. Пиши коротко, по-русски, без воды. Про компанию ничего не придумывай: только то, что есть в вакансии и в сообщении работодателя.

## Вакансия

### [id=1] Go-разработчик 1 - Компания 1
Зарплата: 150000-250000 RUR | Формат: remote | Регион: Москва | Тестовое: нет | Письмо обязательно: да | Язык вакансии: русский
Описание:
Ищем Go-разработчика в команду платежей. Нужен опыт с Go, PostgreSQL, Redis, Docker. Плюсом будет Kafka. Задачи: интеграции с внешними API, биллинг, мониторинг. Вакансия номер 1.

## Приглашение от работодателя

Приглашаем на техническое собеседование в четверг.

## Что вернуть

- `questions` - 5 технических вопросов, которые вероятнее всего зададут по стеку и задачам из вакансии. Каждый - одна строка.
- `stories` - 3 истории из реального опыта соискателя (только из `profile` и резюме), которые стоит рассказать: `skill` - навык из вакансии, `prompt` - 1-2 предложения, какой случай из опыта вспомнить и на что сделать акцент. Никаких выдуманных проектов, цифр и компаний.
- `gaps` - требования вакансии, которых нет в `profile.verified_skills` (и всё из «никогда не заявлять», если вакансия этого просит), каждое с честной строкой «как ответить»: в продакшене не использовал, смежный опыт такой-то, готов быстро разобраться. Пусто, если пробелов нет.
- `ask_them` - 3 коротких вопроса работодателю про команду, задачи и процесс, опираясь на вакансию.

## Схема ответа

```json
{
  "questions": string[],
  "stories": [{ "skill": string, "prompt": string }],
  "gaps": string[],
  "ask_them": string[]
}
```

Верни только JSON.
